# 오늘의 AI 네 컷 33: 초대형 AI 모델의 가중치가 열렸다

1. 훅 — 누리가 잠금이 열린 거대한 모델 상자와 내려받기 화살표를 보며 직접 받을 수 있는지 묻는다. (C1, C2)
2. 사실 — 픽이 열린 모델 가중치 묶음과 공개 저장소를 가리키며 실제 다운로드 가능 상태를 설명한다. (C1, C2)
3. 의미 — 누리가 작은 개인용 PC 옆에서 바로 실행할 수 있는지 확인한다. (C3, C4)
4. 한계 — 픽이 1.21TB 저장 장치와 여러 장의 고성능 GPU가 꽂힌 서버 랙을 가리키며 배포 문턱을 짚는다. (C3, C4, C5)

불확실성 잠금 — 공개된 것은 모델 가중치와 배포 자료이며, 회사 성능표가 모든 실제 업무에서 재현됐거나 일반 PC에서 쉽게 실행된다는 뜻은 아니다.
