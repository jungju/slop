# 오늘의 AI 네 컷 4: GPT-5.6 Sol 가격이 내려갔다

1. 훅 — 누리가 가격표가 내려가는 화면을 보고 가장 강한 GPT의 이용료가 실제로 낮아졌는지 묻는다. (C1)
2. 사실 — 픽이 입력과 출력 가격표를 나란히 펼쳐 새 API 단가를 보여 준다. (C2, C3)
3. 의미 — 누리가 큰 작업 더미와 낮아진 비용 계산기를 비교하며 같은 사용량의 비용이 줄었음을 확인한다. (C4)
4. 결론 — 픽이 3개월 달력을 가리키며 이번 가격이 한시적이고 이후 가격은 아직 공개되지 않았다고 정리한다. (C5, C6)

불확실성 잠금: 가격 인하가 모델 성능 향상이나 모든 사용자 요금제 인하를 뜻한다고 넓히지 않으며, 프로모션 종료 뒤 가격을 예측하지 않는다.
