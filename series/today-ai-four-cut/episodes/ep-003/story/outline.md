# 오늘의 AI 네 컷 3: 강한 보안 AI가 방어 도구에 들어갔다

1. 훅 — 누리가 방패와 경고 표시가 뜬 코드 화면 앞에서 공격에도 강한 AI를 방어에 써도 되는지 묻는다. (C1, C6)
2. 사실 — 픽이 Claude Security 안에서 Mythos 5가 코드 취약점을 찾아 수정안을 내는 흐름을 보여 준다. (C2, C3)
3. 의미 — 누리가 잠긴 모델 상자와 그 밖으로 나온 패치 카드만 비교하며 직접 접근이 제한됨을 확인한다. (C4)
4. 결론 — 픽이 사람 검토자가 승인 도장을 찍기 전에는 수정안이 적용되지 않는 장면을 가리킨다. (C5, C7)

불확실성 잠금: 독립 평가는 이전 Mythos Preview와 단순화된 시험 환경을 다뤘으므로, 이번 제품이 모든 실제 취약점을 찾거나 안전 문제를 자동 해결한다고 말하지 않는다.
