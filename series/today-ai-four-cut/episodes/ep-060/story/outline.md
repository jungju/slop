# 오늘의 AI 네 컷 60: Hy4 모델 가중치가 공개됐다

1. 훅 — 누리가 열린 보관함에서 내려오는 세 개의 모델 상자를 보며 Hy4를 직접 받을 수 있는지 묻는다. (C1, C2)
2. 사실 — 픽이 지시형, FP8, 사전학습을 뜻하는 서로 다른 모양의 세 상자를 공개 선반에 정리하며 가중치 세 종류가 공개됐다고 설명한다. (C2, C3)
3. 의미 — 누리가 작은 개인용 컴퓨터 옆에서 거대한 서버 탑을 올려다보며 누구나 바로 실행할 수 있는지 확인한다. (C4, C5)
4. 결론 — 픽이 서버 장비 체크표와 사용 조건 문서를 함께 가리키며 실행 전 두 조건을 확인하라고 정리한다. (C5, C6, C7)

불확실성 잠금: 가중치의 공개와 모델 규모·공식 실행 예시는 확인됐지만 정확한 공개 시각은 Tencent가 따로 밝히지 않았고, 실제 장비 요구량과 라이선스 적용은 선택한 모델 형식과 사용 방식에 따라 달라진다.
