# 오늘의 AI 네 컷 53: 포토샵이 외부 AI와 연결된다

1. 훅 — 누리가 편집 중인 이미지 파일 옆에 나타난 외부 AI 비서 연결선을 보고, AI가 프로젝트 파일까지 고치는지 묻는다. (C1, C2)
2. 사실 — 픽이 네 종류의 무문자 창작 앱 아이콘과 하나의 연결 포트를 가리키며 Adobe의 로컬 MCP 미리보기를 설명한다. (C2, C3)
3. 의미 — 누리가 층층이 쌓인 레이어와 영상 시퀀스를 확인하며 편집 구조가 보존되는지 묻는다. (C4)
4. 결론 — 픽이 편집 가능한 층과 작은 시험 표식을 함께 보여 주며 아직 미리보기이고 공개 범위를 조정 중임을 짚는다. (C5, C6)

불확실성 잠금: 로컬 MCP 통합은 발표 시점의 미리보기이며, Adobe는 외부 에이전트에 노출할 기능의 범위를 사용자 피드백을 보며 정하고 있다고 밝혔다.
