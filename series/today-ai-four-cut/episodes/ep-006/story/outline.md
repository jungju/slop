# 오늘의 AI 네 컷 6: 같은 Claude를 두 길로 나눴다

1. 훅 — 누리가 하나의 모델 코어에서 두 갈래 길이 뻗는 장면을 보며 새 Claude가 왜 두 가지인지 묻는다. (C1)
2. 사실 — 픽이 열린 문으로 가는 Fable 5.1 경로와 자물쇠가 있는 Mythos 5.1 경로를 가리키며 공개 범위를 설명한다. (C2, C3)
3. 의미 — 누리가 두 경로의 중심에 같은 모델 코어가 놓인 것을 확인하며 차이가 무엇인지 묻는다. (C4)
4. 결론 — 픽이 방패와 검증 배지를 가리키며 고위험 보안·생물학 기능은 검증된 기관에만 제한된다고 설명한다. (C5, C6)

불확실성 잠금: 두 모델이 모든 기능에서 완전히 다르다고 묘사하지 않고, 같은 기반 모델에 서로 다른 보호 장치와 접근 조건을 둔 발표임을 3·4컷에서 분명히 밝힌다.
