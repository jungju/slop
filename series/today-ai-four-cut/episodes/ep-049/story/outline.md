# 오늘의 AI 네 컷 49: Codex에 코드 저장 도구가 온다

1. 훅 — 누리가 여러 코드 가지가 동시에 쌓이는 작업대를 보며 AI가 쓰는 코드가 늘면 저장 도구도 달라지는지 묻는다. (C1, C2)
2. 사실 — 픽이 파일 나무·변경 비교·코드 보관 상자를 하나의 도구함에 모으며 OpenAI의 Pierre 인수 계획을 설명한다. (C2, C3, C4)
3. 의미 — 누리가 다리로 연결되기 전 두 개의 별도 건물을 보며 이미 Codex 안으로 합쳐졌는지 확인한다. (C5, C6)
4. 결론 — 픽이 승인 도장을 기다리는 거래 서류와 떨어져 있는 두 건물을 가리키며 인수 발표와 완료를 구분한다. (C5, C6)

불확실성 잠금: OpenAI는 Pierre를 인수하기로 발표했지만 거래는 규제 승인을 포함한 종결 조건을 남겨 두고 있으며, 완료 전까지 두 회사는 별도다.
